## 1. 왜 만들었나

유디트의 실제 병목: **소재는 레퍼에서 찾아오는데, 그걸로 훅 짜는 데서 항상 막힌다.**
앤에게 훅을 시키면 "끼워맞춰서 엉망으로" 나온다.

원인 두 개를 찾았다. 둘 다 규칙이 없어서가 아니라 **규칙 때문**이었다.

- ① 프롬프트가 "13앵글을 **순서대로 다 채워라**"라고 시킨다 → 안 맞는 앵글에도 억지 문장이 나온다
- 점검 기준이 "표지·**훅 둘 다** 주제·권위·이득이 드러나나"다 → 훅에 요소 3개를 요구하니 훅이 길어지고 설명이 된다

## 2. 만든 것 — 훅 짜는 순서

앵글에서 출발하지 말고 **사실에서 출발**한다.

```
1. 사실 5줄       ← 훅처럼 쓰지 말고 사실만
2. 어긋남 고르기   ← 정보 많은 줄 말고 '어?' 싶은 줄
3. 훅 8개         ← 고른 어긋남에 맞는 앵글만
4. 추천 1~2개 + 이유
5. 표지는 훅 확정 후
```

### 사실 5줄

| | 내용 |
|---|---|
| 1 | **숫자** — 이 얘기에서 제일 센 숫자 (금액·기간·횟수) |
| 2 | **전후** — 전엔 이랬는데 지금은 이렇다 |
| 3 | **내가 틀렸던 것** — 나도 몰랐거나 반대로 알고 있었던 것 |
| 4 | **남들이 하는 것** — 다들 이렇게 하더라 |
| 5 | **내가 안 하는 것** — 근데 나는 이건 안 한다 |

→ **3·4·5번이 훅 재료**다. 1·2번은 본문 재료다.

### 역할 분담

| | 담당 |
|---|---|
| 표지 | 알맹이 — 주제 · 결과/숫자/리스트 · 대상 |
| 훅 | **어긋남 하나. 그게 전부** |
| 인트로 | 주제 + 권위 + 이득 |

훅에 주제·권위·이득을 다 넣으려 하면 훅이 망가진다. 그건 인트로 몫이다.

### 금지

- **소재·방법·개수를 훅에 넣지 마라** — "마일리지 적립 7가지 방법"이 소재면 훅에 "7가지 방법"이 없다. 방법은 본문 몫, 훅은 어긋남 몫.
  근거: 레퍼 68 — 훅은 "처음 비즈니스를 탔는데요", 방법은 "10가지나 되더라고요"로 개수만
- **앵글 순회 금지** — 앵글은 메뉴지 체크리스트가 아니다
- **가짜 숫자 금지** — 유디트 실제 수치가 아니면 `[ ]`로 비운다
- **사실 5줄을 지어내지 마라** — 유디트가 준 것에서 안 나오는 줄은 비우고 질문으로. 각 줄에 `[유디트]` / `[질문]` 출처를 표시하게 하면 지어낸 줄이 보인다

## 3. 검증된 것 (우리 레퍼가 근거)

- **숫자 × 질문** — 자랑할 성과에 숫자를 박고 단정 대신 질문으로. 자랑인데 자랑으로 안 읽힌다
  · 근거: 레퍼 2 "대기업 어떻게 5번이나 합격했을까?" (유디트 본인 것)
- **남의 말로 열기 = 인용 어미** — `~냐고요?` `~물어보길래` `~래요`. **따옴표는 아니다**
  · 근거: 레퍼 19·20·24·52. 우리 레퍼에 따옴표 훅은 0개. 20번 터진 이유가 "대화 인용 — 광고 느낌 없이 자연 진입"
  · 단, 라이프 카테고리에서만 검증됨. 재테크·커리어는 미검증
- **한 방 단어** — 설명 없이 0.5초에 감정이 오는 단어가 하나 있나 (레퍼 2의 "5번이나")
- **목적 치환** — 숫자·기능이 나오면 장면으로 바꿔보고 더 센 쪽. "22만 마일리지"보다 "다리 쭉 뻗고 10시간"
  · 근거: 레퍼 24 터진 이유 "욕망 장면 — 갖고 싶게 만든 후"
- **권위 × 손해** — 누가 하는 경고인지가 무게를 만든다. 권위 없는 경고는 잔소리로 읽힌다

## 4. 가설 (검증 안 됨 — 상품 카피 레퍼 출처)

정보형 훅에 그대로 쓰면 톤이 깨진다. **광고·협찬 편에서 먼저 써보고**, 우리 채널에서 실제로 터지면 그때 규칙으로 올린다.

- **누군가의 한 마디** — 사람 입에서 나온 말 한 줄로 연다 (출처: 백설공주 카피)
- **시한폭탄** — 막연한 계절 대신 시청자의 D-day를 박는다 (출처: 전남친 결혼식 2주 전)
  · 우리 쪽 D-day 후보: 연말정산 · 청약 · 혼인신고 · 항공권 특가 시즌
- **오감 경고** — 사라고 하지 않고 말리면서 감각을 자극한다 (출처: 물티슈 카피). 위 '목적 치환'과 같은 계열이라 겹치면 하나만
- **단점 먼저 인정 후 뒤집기** — 협찬에서 다 좋다고만 하면 안 믿는다

## 4-2. ★경로 여러 개 (2026-08-03 저녁 — 여기가 제일 값나가는 부분)

오늘 실패한 진짜 이유: **훅 짜는 절차를 하나로 만들려고 했다.**
13앵글 순회를 걷어내고 그 자리에 `사실 5줄 → 어긋남 → 훅 8개`를 또 하나의 필수 절차로 앉혔다.
틀만 바꿨지 여전히 하나의 틀이라, 재료가 없는데도 그 경로로 밀어넣으니 앤이 사실을 지어냈다.

**경로는 여러 개여야 하고, 가진 재료로 갈린다.**

| 갖고 있는 것 | 쓸 경로 |
|---|---|
| **소재만** 있다 | **추상화 사다리** — 소재 → 이득 → 장면, 두 칸 |
| **내 경험·숫자**가 있다 | **어긋남** — 사실 5줄에서 이상한 줄 |
| **아무것도** 없다 | **가정 시나리오** — "~해야 한다면요" |
| **들은 말**이 있다 (댓글·DM·주변) | **남의 말 인용** — 그 말로 연다 |
| **좋은 레퍼**가 있다 | **긴장 이식** — 그 찝찝함이 내 주제에도 생기나 |

앵글 13개가 **무엇을 말할까**의 메뉴라면, 경로는 **어떻게 도달할까**의 메뉴다. 층이 달라 둘 다 있어도 안 부딪힌다.

### 경로 A — 추상화 사다리 (소재만 있을 때)

```
0층  AI 동요 만드는 법        ← 소재. 관심 있는 사람만 봄
1층  돈 빨리 버는 법          ← 이득. 대상이 확 넓어짐
2층  다 잃고 28일 안에 M4     ← 상황. 그림이 생기고 감정이 붙음
```

두 칸 올라갔기 때문에 훅에 "AI 동요"가 한 글자도 없다.

기존 규칙은 "소재를 훅에 넣지 마라"까지만 있고 **어디로 가라**가 없었다. 그래서 앤이 소재를 뺀 뒤 1층(정보)에서 멈췄다 — "마일리지, 비행기에서 안 모입니다"가 그 예다. 소재는 뺐지만 그림이 없다.

**우리 검증 레퍼는 전부 2층에 있다.** 1층에서 멈춘 훅은 하나도 없다.

| 레퍼 | 0층이었다면 | 실제 훅 (2층) |
|---|---|---|
| 68 | 마일리지 모으는 10가지 방법 | 저 이번에 처음 비즈니스를 탔는데요 |
| 24 | 마일리지 카드 비교 | 어떻게 매번 비즈니스 타냐고요? |
| 19 | 신혼집 싸게 꾸미는 법 | 신혼집 얼마 들었냐고요? 100만원도 안 들었어요 |

→ 규칙은 "소재를 넣지 마라"가 아니라 **"소재에서 두 칸 올라가라. 이득까지면 1층, 장면까지 가야 2층"**

### 경로 C — 가정 시나리오 (재료가 아무것도 없을 때)

원본: *"내가 모든 걸 잃었는데 28일 안에 BMW M4를 사야 한다면 나는 이렇게 할 거야"* (릴스에서 실제 사용)

- 하려던 말을 한 줄로 쓴다 → 그 말이 가장 절박해지는 상황을 지어낸다 → 나를 그 안에 넣는다
- 상황에 세 개가 필요하다: **리셋**(핑곗거리 제거) · **기한**(절박함) · **갖고 싶은 것**(숫자 말고 그림)
- 주어가 '나'인데도 작동한다. "알려드릴게요"(제공 예고)가 아니라 "나는 이렇게 할 거야"(실행 선언)라서. 훈수가 아니라 시연이다
- **사실이 없어도 쓸 수 있는 유일한 합법 경로.** 사실을 주장하는 게 아니라 가정을 세우는 것이라 "지어내지 마라" 규칙에 걸리지 않는다. 단 `~한다면`이 명시돼야 한다
- 본문은 절차형이어야 한다. 훅에서 "이렇게 할 거예요"라고 선언했으니 순서가 나와야 약속을 지킨다

변환 예:

| 하려던 말 | 바꾼 말 |
|---|---|
| 마일리지 적립하는 7가지 방법 | 마일리지 0인데 3개월 뒤 유럽 가야 한다면요 |
| 월급 관리하는 법 | 통장 다 털렸는데 1년 뒤 집 계약해야 한다면요 |
| 연말정산 잘 받는 법 | 올해 아무것도 안 해놨는데 환급은 받아야 한다면요 |

### 해외 훅 번역할 때

영어권 훅은 **주어로 지목**한다(`You're doing it wrong`). 직역하면 "당신은 잘못하고 있습니다"가 되어 무례하게 들린다.
우리 레퍼는 전부 **어미로 지목**한다 — `아직도 그렇게 하세요?` `~하시죠?`. 이 변환만 지키면 대부분 살아난다.

우리에 없는 해외 포맷 중 검토할 만한 것: **챌린지형**(30일 동안 X 해봤어요) · **대비형**(돈 모으는 부부는 이거 안 해요) · **0원 프레임**(0원으로 유럽 다녀온 방법) · **구매 직전 저지**(그 카드 만들기 전에 이거 보세요).

## 5. 실험 기록 — 세 번 돌려보고 나온 것

### 1차 (전체 규칙 버전)
- 훅 8개가 전부 `~습니다`로 나옴 → **문장 전환 원칙의 예시가 합니다체라 말투 견본으로 읽혔다.** 원칙 예시와 말투 견본은 분리해야 한다
- 8개 중 2개가 규칙 위반인데 "전부 통과"라고 자평 → **자기 점검 선언은 못 하게 막아야 한다**
- 경험 칸이 비어 사실 5줄이 전부 `[ ]`인데도 훅을 냄

### 2차 (다이어트 — 규칙을 절반으로)
- 말투는 살아남 (`~쌓여요` `~모으더라고요`). **말투를 프롬프트에 직접 박은 게 먹혔다**
- 훅이 35~40자로 길어지고 앵글명을 지어냄 → 다이어트하며 길이 규칙·앵글 목록을 코드 모드에서 빠뜨린 탓
- **경험 한 줄만 줬는데 사실 5줄을 다 채웠다.** 3·4·5번 전부 앤이 만든 것. 훅이 가짜 사실 위에 지어졌고, 문장이 매끈해서 리뷰에서도 못 알아봤다

### 3차 (스킬 읽은 쪽)
- 재료가 없자 **훅 대신 질문 3개를 던졌다.** 이게 이 순서의 정답 동작이다

### 결론
- **훅의 질은 규칙이 아니라 재료가 정한다.** 프롬프트 튜닝으로 얻을 수 있는 건 여기까지고, 나머지는 유디트 사실이 채워야 한다
- 규칙을 늘릴수록 앤은 생각을 안 하고 칸을 채운다. 늘릴 때마다 실제로 나빠졌다
- 스킬(세계관·서사라이브러리)을 못 읽어도 훅 결과는 크게 달라지지 않았다. 세계관은 2단계 대본에서 필요하다

## 6. 다시 시도한다면

1. **재료부터.** 훅 규칙을 손대기 전에, 유디트가 3·4·5번(내가 틀렸던 것 / 남들이 하는 것 / 내가 안 하는 것)을 채우는 흐름을 먼저 만든다. 재료 없이 프롬프트만 고치면 세 번 다 같은 자리에서 막힌다
2. **한 번에 하나만 바꾸고 돌려본다.** 이번엔 여러 개를 한꺼번에 넣어서 뭐가 효과였는지 분리가 안 됐다
3. **먼저 손댈 곳은 13앵글 순회 강제** — 끼워맞추기의 직접 원인이고, 이건 세 번 다 재현됐다
4. **절차 하나로 만들지 마라.** 스킬은 `훅 짜는 순서 = 이 절차를 따라라`가 아니라
   **`경로 5개 + 재료 보고 고르기`**로 설계한다 (4-2 참고). 오늘 실패의 근본 원인이 여기다
