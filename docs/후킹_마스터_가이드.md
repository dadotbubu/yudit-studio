# 번뜩이는 훅 만들기

> 그냥 훅이 아닌, 번뜩이는 훅을 만든다

---

## 핵심

| 원칙 | 설명 |
|------|------|
| **템플릿 채우기 ❌** | 단어의 충돌 + 발상의 전환 ✅ |
| **목표** | 누군가의 이야기/노하우처럼 느껴지게 → 궁금해서 끝까지 보게 |
| **프로세스** | 컨셉 정하기 → 각도 틀기 → 무기 1개 적용 → 체크 |
| **강한 단어** | 눈길이 가는 포인트 |

### 4가지 무기

| 무기 | 설명 | 예시 |
|------|------|------|
| **단어 충돌** | 어울리지 않는 단어의 조합으로 긴장감 | "성공한 실패", "게으른 부자" |
| **예상 뒤집기** | 당연한 상식을 반대로 | "물 많이 먹어도 피부 안좋은 사람 특징" |
| **구체적 디테일** | 숫자, 고유명사, 특정 상황 | "3년 전 그날 펑펑 울었다" |
| **강한 단어** | 감정을 자극하는 임팩트 있는 표현 | "폭발", "충격", "절대", "진짜" |

## 유디트의 훅 3원칙 (항상 참고, 모든 훅 통과 체크)

1. **"뻔한 건 싫다"** — 유튜버 말투 금지 ("궁금하시죠?" / "알려드릴게요" / "놀라지 마세요")
2. **"14년 차의 짬바가 느껴져야 한다"** — 권위와 여유. 초조하지 않고 툭 던지듯
3. **"산뜻하게 터지는 맛이 있어야 한다"** — 트렌디한 숏폼 문법. 길게 설명 X, 한 방

## Part 1. 대표 후킹 5가지 유형

| 유형 | 설명 | 예시 |
|------|------|------|
| **다른 사람의 한마디** | 제3자의 말을 인용해 신뢰감 부여 | "이거 왜 이렇게 비싸요?" |
| **단정짓는 말** | 확신에 찬 한마디로 주목 | "와 이게 되네요" |
| **혜택 제시** | 구체적 결과를 먼저 보여줌 | "이거 하나로 5kg 빠져보여요" |
| **특정 에피소드** | 개인적 스토리로 감정 연결 | "3년 전 나는 그날 펑펑 울었다" |
| **상식 뒤집기** | 기존 믿음을 반박해 호기심 유발 | "물 많이 먹어도 피부 안좋은 사람 특징" |

## Part 2. 핵심 심리 원리

| 심리 원리 | 설명 | 활용법 |
|-----------|------|--------|
| **손실 회피** | 얻는 것보다 잃는 것에 2배 더 강하게 반응 | "~하는 법" → "~안 하면 손해" |
| **소외 불안** | 무리에서 나만 모르는 것에 대한 두려움 | "너만 빼고 다 알고 있어" |
| **인지적 긴장** | 기존 믿음이 흔들릴 때 주목 | 상식 뒤집기, 반전 |
| **희소성** | 아무나 모르는 정보는 더 가치있어 보임 | "비밀", "숨겨진", "진짜" |
| **구체성** | 숫자와 데이터는 신뢰감 부여 | 막연한 표현 → 숫자로 변환 |

## Part 3. 6가지 후킹 공식

### 1. 충격 요소 + 일반적 믿음 뒤집기형
```
[당연하게 믿는 사실] → [반대 결과/충격]
```
- "대기업 가면 인생 편하다?" → "대기업 7년차가 말하는 진짜 현실"
- "연봉 높으면 부자 된다?" → "연봉 1억이어도 가난한 이유"
- "자기계발 열심히 하면 된다?" → "7관왕 부부가 말하는 자기계발 함정"

### 2. 숫자 + 효과 보장형
```
[구체적 숫자] + [명확한 효과/결과]
```
- "자소서 잘 쓰는 법" → "이 3가지만 고쳤더니 서류 합격률 2배"
- "월급관리 팁" → "이 앱 하나로 한 달 50만원 절약"
- "면접 준비" → "이 질문 5개만 외워도 최종 합격"

### 3. 궁금증 유발 + 결과 암시형
```
[행동을 멈추면/바꾸면] → [극적인 결과]
```
- "대기업 취업 비법" → "당신도 모르게 하고 있을 서류 탈락 습관"
- "재테크 추천" → "이 투자, 오히려 손해일 수 있습니다"
- "연봉 협상" → "이거 모르면 수천만원 손해 봅니다"
- 모든 정보를 한번에 주지 말고 '여운'을 주세요

### 4. 비밀 + 희소성 강조형
```
[일반 주제] → [특정 집단만 아는 비밀]
```
- "대기업 합격법" → "7관왕 부부만 아는 서류 합격 공식 3가지"
- "자산 관리" → "30대 맞벌이만 아는 세금 아끼는 법"
- "AI 활용" → "직장인 95%는 아직 모르는 ChatGPT 업무 활용법"

### 5. 반전 + 기대와 다른 결과형
```
[당연히 맞다고 생각하는 것] → [뒤집는 것]
```
- "대기업 가야 한다?" → "오히려 대기업 안 가는 게 나았던 이유"
- "무조건 저축해야 한다?" → "저축만 열심히 하다 손해 보는 이유"
- "열심히 일해야 성공한다?" → "7관왕 부부가 오히려 일을 줄인 이유"

### 6. CTA(행동 유도) + 긴급성형
```
[긴급한 상황/기회] + [놓치면 안 되는 경우]
```
- "취업 준비해야지" → "올해 안에 이거 안 하면 내년은 더 힘듭니다"
- "AI 배워볼까?" → "지금 안 배우면 2년 뒤 자리 위험합니다"
- "연말정산 챙겨야지" → "이거 놓치면 100만원 그냥 날립니다"

## Part 4. 8가지 실전 템플릿

### 1. 정보 제공 및 아이템 추천
특정 아이템이나 정보를 리스트 형식으로 제안

| 템플릿 | 예시 |
|--------|------|
| `[장소]에서 꼭 사야하는 [주제]템 N가지` | 다이소에서 꼭 사야하는 수납템 5가지 |
| `[직업]이 추천하는 [OO템]` | 피부과 의사가 추천하는 선크림 |
| `[전문분야] N년차 쿠팡템 N가지` | 육아 7년차 쿠팡템 10가지 |
| `나만 알고 싶은 인생 [아이템] N종` | 나만 알고 싶은 인생 주방템 5종 |
| `[타겟] 무조건 추천! [아이템] BEST N` | 자취생 무조건 추천! 가전 BEST 3 |

---

### 2. 문제 해결 및 노하우 전수
현실적인 고민을 해결해주거나 돈/시간을 아껴주는 실용적인 훅

| 템플릿 | 예시 |
|--------|------|
| `[시간] 내 [해결] 할 수 있는 현실적인 방법` | 하루 10분 내 뱃살 뺄 수 있는 현실적인 방법 |
| `[문제], 이렇게 해야 [해결] 되요` | 여드름, 이렇게 해야 진짜 사라져요 |
| `평생 써먹는 [문제 해결]` | 평생 써먹는 엑셀 단축키 |
| `99%가 모르는 [물건] 싸게 사는 법` | 99%가 모르는 항공권 싸게 사는 법 |
| `[문제] 증상별 [해결책] 총정리` | 두통 증상별 해결책 총정리 |

---

### 3. 비교 및 변화 (Before & After)
대조적인 상황을 보여주어 시각적인 호기심과 공감을 자극

| 템플릿 | 예시 |
|--------|------|
| `[주제] 나쁜 습관 vs 좋은 습관` | 수면 나쁜 습관 vs 좋은 습관 |
| `전문가 vs 나` | 전문가 vs 나 (요리편) |
| `[변화] 만들어 준 [방법] N가지` | 인생 바꿔준 습관 3가지 |
| `[아이템/행동]만 바꿔도 느낌 확 바뀜` | 조명만 바꿔도 느낌 확 바뀜 |
| `[부정적 행동] vs [긍정적 행동]` | 돈 새는 습관 vs 돈 모이는 습관 |

---

### 4. 경고 및 통념 반박
시청자가 놓치고 있는 실수나 잘못된 상식을 지적

| 템플릿 | 예시 |
|--------|------|
| `절대금지 [아이템] N가지` | 절대금지 다이어트 음식 5가지 |
| `이거 없으면 [금액] 날립니다` | 이거 없으면 100만원 날립니다 |
| `요즘에는 [이런거] 안합니다` | 요즘에는 명함 안 돌립니다 |
| `제발 이것만은 피해주세요! [흔한 실수] N가지` | 제발 이것만은 피해주세요! 이력서 실수 3가지 |
| `[평범한 행동]했는데 [충격적 결과]가 나왔다` | 물만 마셨는데 피부가 망가졌다 |

---

### 5. 스토리텔링 및 선언
개인적인 서사나 도전 과정을 통해 진정성과 몰입감

| 템플릿 | 예시 |
|--------|------|
| `저는 지금부터 [기한] 안에 [목표]를 이룰 겁니다!` | 저는 지금부터 100일 안에 10kg 뺄 겁니다! |
| `N년전 [일]을 그만두고 사업을 시작했다` | 3년 전 대기업을 그만두고 사업을 시작했다 |
| `나는 실패한 [나이]이다` | 나는 실패한 30대다 |
| `[부족한 상태]에서 [성공 상태]가 되기까지` | 월 100만원에서 월 1억이 되기까지 |
| `나는 [부정적 상태]여도 괜찮은 줄 알았다` | 나는 번아웃이어도 괜찮은 줄 알았다 |

---

### 6. 권위 활용 및 일상 공개
자신의 전문성이나 일상적인 루틴을 보여주어 신뢰를 형성

| 템플릿 | 예시 |
|--------|------|
| `[나이]라면 더 늦기 전에 반드시 알아야 하는 N가지` | 30대라면 더 늦기 전에 반드시 알아야 하는 5가지 |
| `월 [소득] [직업]이 숨기는 비밀 N가지` | 월 3천 프리랜서가 숨기는 비밀 3가지 |
| `[매장 직원] 추천템 N가지` | 올리브영 직원 추천템 5가지 |
| `[직업]의 [모닝/일상/저녁] 루틴` | CEO의 새벽 루틴 |
| `N년차 [직업]의 월급 공개` | 5년차 개발자의 월급 공개 |

---

### 7. 질문 및 호기심 유발
예상치 못한 질문이나 미스터리한 요소로 궁금증

| 템플릿 | 예시 |
|--------|------|
| `이게 요즘 해외에서 난리난 [물건]이라던데…` | 이게 요즘 해외에서 난리난 다이어트법이라던데… |
| `한국인 대부분이 놓치는 [특정] 비밀` | 한국인 대부분이 놓치는 세금 환급 비밀 |
| `과연 [직업]이 [시간]안에 [상황] 가능할까요?` | 과연 요리사가 10분 안에 코스요리 가능할까요? |
| `제가 처음 [새로운 환경]에 들어와서 가장 놀랐던 게 뭔지 아세요?` | 제가 처음 대기업에 들어와서 가장 놀랐던 게 뭔지 아세요? |

### 8. 오프닝 & 클로징 멘트
영상 앞뒤에 붙여 분위기를 환기하거나 다음 영상을 기대하게 만드는 멘트

| 유형 | 멘트 | 용도 |
|------|------|------|
| **오프닝** | "아니 여러분~" | 친근한 시작 |
| **오프닝** | "그거 아세요?~" | 호기심 유발 시작 |
| **오프닝** | "거봐요 제가 진짜 좋다고 했잖아요~" | 기존 시청자에게 신뢰 |
| **클로징** | "알고보니~ 다음화에 계속" | 시리즈 연결 |
| **클로징** | "과연 [OO]의 운명은?" | 다음 편 기대감 |

## Part 5. 카피 수집처 10곳

| # | 소스 | 무엇을 볼 것 |
|---|------|-------------|
| 1 | **고객 리뷰** | 쿠팡, 네이버 쇼핑에서 "이거 진짜..." 뒤에 나오는 표현 |
| 2 | **메타 광고 보관함** | 경쟁사가 오래 돌리는 광고 = 성과 좋은 카피 |
| 3 | **내 유튜브 시청 기록** | 내가 클릭한 영상 제목 = 이미 검증된 후킹 |
| 4 | **와디즈 펀딩 페이지** | 문제 → 공감 → 해결 구조의 교과서 |
| 5 | **베스트셀러 책 제목** | "죽고 싶지만 떡볶이는 먹고 싶어" 같은 감정 자극 |
| 6 | **카카오 플친 채널** | 타겟 겹치는 브랜드의 광고 문구, 감성+설득 동시에 |
| 7 | **인스타 릴스** | 눈 멈추게 한 한 줄 저장 = 콘텐츠 카피로 바로 활용 |
| 8 | **29cm 상품 설명** | 평범한 물건도 특별하게 만드는 문장이 가득 |
| 9 | **뉴스레터 제목** | 클릭 유도형 카피 모음집 (내가 열어본 제목들) |
| 10 | **카카오메이커스** | 짧지만 핵심인 카피, 제품명 바로 아래 한 줄 |
| + | **스레드 5천 조회수+ 첫 문장** | 터진 이유는 오프너 한 문장에 있음 |

## Part 6. 빠른 참조표

### 상황별 공식 선택
| 상황 | 추천 공식 |
|------|----------|
| 정보/리스트 콘텐츠 | 숫자 + 효과 보장형 |
| 문제 해결 콘텐츠 | 충격 요소 + 뒤집기형, 비밀 + 희소성 강조형 |
| 브이로그/일상 | 스토리텔링, 권위 활용 |
| 비교 콘텐츠 | 비교 및 변화형 |
| 경고/주의 콘텐츠 | 경고 및 통념 반박 |
| 트렌드 콘텐츠 | 질문 및 호기심 유발 |

### Before → After 변환
| Before | After | 사용 공식 |
|--------|-------|----------|
| ~하는 법 | ~안 하면 손해 | 충격 + 뒤집기 |
| ~추천 | 이 ~만 해도 [숫자] 결과 | 숫자 + 효과 보장 |
| ~해야 한다? | 오히려 ~하면 망하는 이유 | 반전 |
| ~방법 | [특정 집단]만 아는 ~ | 비밀 + 희소성 |
| ~하고 싶다면 | ~, 오늘부터 안 하면 끝 | CTA + 긴급성 |
| ~하세요 | 너만 빼고 다 ~ | 소외 불안 |
