## 스튜디오 데이터 입력 주의사항

### 텍스트 필드에 따옴표 넣지 말 것 (쌍따옴표 절대 금지)
스튜디오 레퍼런스 분석·기타 text input 필드는 `<input value="${값}">` 구조로 렌더링됨.
값에 쌍따옴표(")가 들어가면 HTML 속성이 조기 종료되어 **필드가 잘림**.

또한 bash heredoc으로 Python 실행 시 유니코드 꺾쇠(" ")도 ASCII 쌍따옴표(")로 자동 변환될 수 있어 신뢰 불가.

**원칙**: 레퍼·대본 등 스튜디오에 들어가는 모든 텍스트 필드는 **따옴표 자체를 쓰지 말 것**. 인용 강조는 괄호(「 」 또는 ( ))나 줄바꿈으로 대체.

- ❌ `"이제는 클로드가" → "비밀공개"` (쌍따옴표 → 속성 조기 종료)
- ❌ `"이제는 클로드가" → "비밀공개"` (꺾쇠도 shell에서 변환 가능)
- ✅ `이제는 클로드가 → 비밀공개` (따옴표 제거)

### 스튜디오 이상 증상 시 — localStorage 비우기
**증상**: Supabase에는 올바른 데이터가 있는데 스튜디오 화면에 안 보이거나 이상한 값(예: hook이 `"1"`로 덮어씌워짐) 표시.
**원인**: 유디트 앱의 localStorage에 오염된 데이터가 남아있고, 앱의 자동저장이 이 값을 Supabase로 계속 덮어씀.
**해결** (크롬 기준):
1. 스튜디오 탭에서 F12 (또는 Cmd+Opt+I)
2. Console 탭에서 실행:
   ```js
   localStorage.clear(); location.reload();
   ```
3. 그 뒤 Supabase에서 깨끗한 데이터 새로 로드됨

> 근본 해결은 app.js 자동저장 버그 수정 필요 (별도 작업).
